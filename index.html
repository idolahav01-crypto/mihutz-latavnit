03

Detection, taste and precision are three different jobs.

So we never do them in one pass. Your project runs through four separate stages — each tuned for exactly one kind of work, with you as the gate in the middle.

  1. Detect — nothing gets fixed yet

    Every file is scanned against all 110 signals. Each finding carries the file path, a verbatim snippet, and a confidence score. In doubt? Reported absent — a false positive here would poison everything downstream.

    deterministic pass · temperature 0 · outputs detection.json + a factual profile of your site

  2. Design — one direction, not 30 patches

    Before touching a single finding, the studio commits to one coherent design direction for your business: one brand color, one type pairing, one layout principle. Every fix is derived from it — so the result reads as one designer's work.

    creative pass · second-order clichés (dark+gold, Playfair, bento) are contractually banned as fixes

  3. You approve — the human gate

    You see the direction first, then every proposed change with its old code and new code side by side. Reject anything. Nothing moves without a yes.

    no automation here, on purpose

  4. Apply — surgical edits only

    Approved changes are applied by exact match. Class names, handlers, routes, forms and imports are preserved verbatim; each edit passes six self-checks or is reverted.

    precision pass · temperature ~0.2 · full change log per edit

  5. Verify — an independent, skeptical reviewer

    A separate QA pass that never saw the reasoning diffs every line: did anything unapproved change? Is each signal actually resolved — or just swapped for the next cliché? Fail, and the edit goes back.

    adversarial pass · temperature 0 · guilty until proven safe

04

What we will never touch

The audit changes how your site reads, never what it does. The final QA pass diffs every line against this contract:

  • Class names, IDs and data-attributes — preserved verbatim
  • Event handlers, form actions, routes and imports — untouched
  • Your logo, your photos, your content — never replaced
  • Your facts — we never invent numbers, testimonials or claims. Missing facts come back to you as questions.

Who this is for

Freelancers and agencies delivering AI-drafted sites to paying clients; small businesses whose "finished" AI site still feels off; anyone shipping to the Israeli market, where RTL and regulation add 31 signals most tools have never heard of.
